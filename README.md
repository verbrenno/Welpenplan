# Welpenplan – Laineys Wurf

Entwicklungsphasen, Tierarzt- und Pflichttermine sowie Lernideen für Laineys Welpen, berechnet aus dem Geburtsdatum.

**Seite:** https://verbrenno.github.io/Welpenplan/

## Geburtsdatum setzen

Das Geburtsdatum lässt sich per Hash an die URL anhängen (`#geburt=JJJJ-MM-TT`), zum Beispiel:

```
https://verbrenno.github.io/Welpenplan/#geburt=2026-08-30
```

Alternativ kann das Datum direkt auf der Seite im Feld „Geburtstag“ geändert werden; die URL wird dann automatisch angepasst.
